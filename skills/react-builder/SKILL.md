# Skill: React Frontend Builder

## Purpose
Construct responsive, modern web user interfaces using modern React, component isolation, state management, and Playwright verification.

## Inputs
- UI/UX requirements and wireframes
- Backend API endpoints
- Design system tokens and styles

## Process
1. Scaffold component hierarchy and layout structure.
2. Implement custom hooks for state management and API communication.
3. Build accessible components with semantic HTML and keyboard navigation.
4. Implement Playwright test scenarios validating user workflows and visual states.

## Outputs
- `src/components/`
- `src/hooks/`
- `tests/e2e/`

## Validation
- Automated Playwright tests verifying DOM rendering, user interactions, and visual layout.
